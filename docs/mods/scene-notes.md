# Scene Notes

Scene Notes provides the **Shared document** button in an active scene, including a created scene. Study Together and Share Your Laptop use the same document. Enable either mod to use the library.

Choose a UTF-8 text or Markdown file up to **512 KB (512,000 bytes)**. Your configured AI provider receives the full active document with every scene request, including the closing. The panel estimates the token count. The actual count and available context depend on your model.

Replacing the file makes the new document the reference for future questions. Removing it tells the characters to stop using the upload. The scene keeps its dialogue and running summary. During laptop sharing, the screen takes priority over the document.

In a playthrough the document stays with the saved scene. A created scene holds it in memory. Documents saved by earlier previews are readable. If a saved document exceeds today's limit, the panel keeps its filename visible and pauses sharing until you replace or remove it.
