# Testing After Hours 0.1.0 (Busy status)

On your Windows machine, in PowerShell, from your local clone of `naudh1r/venus-university`.

## 1. Setup (once)

```powershell
git fetch origin
git switch mod/after-hours                       # first time: git switch -c mod/after-hours origin/mod/after-hours
git reset --hard origin/mod/after-hours          # only if you had an older copy of the branch
npm install
node testsave/harness/install.mjs                # copies the test playthrough into data/saves
npm run dev
```

In a second PowerShell window, follow the log:

```powershell
Get-Content data/app.log -Wait -Tail 20
```

In the game: set your text model as usual (Settings), then **Mods** on the main menu and check
**After Hours** is on, with **Busy status** on.

**The test playthrough** (Load Game → the Quickstart playthrough) has seven manual saves. Use:
- `manual04`: Tuesday March 17, day. 9 contacts, no lover. For most tests.
- `manual07`: Thursday May 21, night before graduation. For the New Game+ test.

Each save first replays its slot's opening; click through it to the landing.

## 2. Tests

Tick each one. If one fails, note the number, what you did, what you saw, and copy the log lines
around it.

### The chip
- [ ] **1.** Open the phone → Chats. Beside the **Chats** title there is a chip: **Online**.
- [ ] **2.** Hover it: the hint "Busy: girls won't ask you to meet up in chats you start." shows.
- [ ] **3.** Click it: it reads **Busy**, its dot changes colour. Click again: **Online**. Leave it on **Busy**.
- [ ] **4.** Day and night: check the chip looks right on a day slot and on a night slot (Relax once
  to reach the night).
- [ ] **5.** Open a thread, then go back to the list: the chip is still there and still says **Busy**.

### Busy drops her invite in a chat you start
- [ ] **6.** Status **Busy**. Pick a friendly contact and **you** send the first text this slot,
  inviting one, for example: "so bored rn, what are you up to?" Keep chatting until she suggests
  meeting up right now. (It may take a few tries; a friendly or flirty girl does it most.)
  **Expected:** no "wants to hang out. Are you down?" footer, no **Begin hangout** button.
  The log shows `[hangout] = contact: …` (the classifier saw her invite) and nothing armed after it.
- [ ] **7.** Same chat, now **you** ask: "want to grab coffee right now?"
  **Expected:** if she agrees, **Begin hangout** appears and works. She may comment that you said you
  were busy.
- [ ] **8.** Status **Online**, a different girl, the same as test 6.
  **Expected:** her invite raises the footer as in the normal game. (Proves Busy is what dropped it.)

### What Busy leaves alone
- [ ] **9.** Status **Busy**. Relax a few slots until a girl texts **you first** at a slot change: an
  invitation (with the Yes/No footer) or a reach-out.
  **Expected:** the footer shows as usual; **Yes** arms the hangout.
- [ ] **10.** Status **Busy**. Reply to her slot-change invitation **by text** ("sure, I'm in").
  **Expected:** it arms the hangout as normal.
- [ ] **11.** Status **Busy**. In a chat you started, agree a plan for **another time**
  ("let's get lunch tomorrow"). Play the slot (Relax is fine).
  **Expected:** the plan is on the calendar afterwards.
- [ ] **12.** In the log, a DM prompt sent while Busy contains "set his Bunnyboard status to Busy".
  While **Online** it does not.

### Saving
- [ ] **13.** Set **Busy** on the landing. Game menu (Escape) → **Return to main menu** → **Continue**.
  **Expected:** still **Busy**.
- [ ] **14.** Set **Busy**, take a manual save, set **Online**, load the manual save.
  **Expected:** **Busy**.
- [ ] **15.** Set **Busy** and play into the next slot (Relax). **Expected:** still **Busy**.

### New semester
- [ ] **16.** Load `manual07`, set **Busy**, Relax to graduation morning, go through the ceremony and
  goodbyes, **Go home**, then **Continue** into the next semester and finish New Game+.
  **Expected:** the first morning of the new semester shows **Online**.

### Switched off
- [ ] **17.** Mods → turn off **Busy status** (keep the mod on). **Expected:** no chip; a girl's invite
  in a chat you started raises the footer again.
- [ ] **18.** Turn it back on. **Expected:** the chip comes back with the status you had saved.
- [ ] **19.** Turn off **After Hours** itself. **Expected:** no chip, the game as before. Turn it
  back on: the saved status is back.

### Other mods
- [ ] **20.** With Bunnyfeeds, Photo Feature and Text Regeneration on, repeat test 6 once.
  **Expected:** the same result, nothing else broken in the thread.

## 3. Afterwards

```powershell
node testsave/harness/install.mjs --remove       # takes the test playthrough out again
```

Report back with the numbers that failed (or "all passed").
