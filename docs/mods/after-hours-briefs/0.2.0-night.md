## What the player gets
- After **every** evening (a scene or Relax), before the morning opens: the landing in his room at night,
  one line, and one row, **End the day (Skip to tomorrow)**. No other rows, no text box. The phone is open:
  texts and Bunnyfeeds comments. No limit, no cost.
- **End the day** asks first; confirmed, the morning opens as the game opens it today.
- The girls know it is late and everyone is in their own dorm. Nobody can meet up tonight: every
  "right now" verdict while the night holds is dropped (visits come in 0.3.0).
- Relax in the evening reads **Relax (Skip to bedtime)**, since it now leads to the night.
- A new option **The night** (`night`, default on). Off: no night, Relax keeps its own words.

## Rules (pure, in `src/shared/afterHours.ts`)
- `nightOwed(to, data)`: `to.time === 0 && to.date > 0 && data.nightDone !== globalSlotOf(to.date, to.time)`.
  (`to.date > 0`: a semester's first morning has no evening before it.) The option is checked by the
  caller.
- Save shape grows: `{ busy: boolean; nightDone?: number }`. `normalize` keeps `nightDone` only when it is
  a whole number. Still no `carry`.

## Hooks (`src/renderer/mods/afterHours.tsx`)
- `slotInterlude`: when the `night` option is on and `nightOwed(to, status.read())`, return
  `{ lines: [nightLine], rows: [endTheDay], clock: 'late-night' }`. `endTheDay.onPick` does
  `status.set({ ...status.read(), nightDone: globalSlotOf(to.date, to.time) })`, so the morning's own
  write carries it.
- `hangoutVerdict`: while `interludeNow()?.owner === 'after-hours'`, return `null`. Otherwise the Busy rule
  as now.
- `prompts.dm`: while the night holds, the night line below (and the Busy line still applies if Busy).
- `relaxLabel`: when the option is on and `time === 1`, `Relax (Skip to bedtime)`.

## Text (in `src/shared/afterHoursText.ts`)
