{{NAME}} {{VERSION}} (unofficial test)
=======================================

A test of a mod that is not in a Venus Extracurriculars release yet. It
installs on top of {{BASE}} and is not made or supported by Venus Dev.

You need {{BASE}} installed. It checks for exactly that version before
changing anything.

Install
-------
1. Close the game.
2. Back up your saves (the "data" folder next to Venus University.exe).
3. Extract this whole zip and double-click Install.cmd. If it asks, paste
   the path of your game folder.
4. Turn the mod on from Mods on the main menu.

Uninstall
---------
Close the game and double-click Uninstall.cmd. The game goes back to
{{BASE}}. Your saves are not touched.

Uninstall this test BEFORE uninstalling Venus Extracurriculars, or before
installing a newer Extracurriculars. Extracurriculars' own Uninstall
refuses to run while this test is installed, and changes nothing.

If the game updates or Extracurriculars is reinstalled, the test is gone;
Uninstall.cmd then just clears what it left behind.
